## Browsing the Catalog

Use the Departments menu to browse products by category and department. Product names link to detail pages with descriptions, costs, images, and attribution details.

## Searching the Catalog

Use the search box in the header. Search results are shareable because the query is stored in the page URL.

The search engine finds catalog records that match the terms, phrases, and boolean operators entered.

| Search | Finds |
| --- | --- |
| `laser pistol` | Records containing both `laser` and `pistol`. |
| `"laser pistol"` | Records containing the exact phrase `laser pistol`. |
| `laser OR maser` | Records containing either term. |
| `laser NOT rifle` | Records containing `laser` but not `rifle`. |
| `(laser OR maser) AND pistol` | Pistol records that also contain `laser` or `maser`. |
| `vacc suit` | Records containing both `vacc` and `suit`. |

Search operators are not case-sensitive. Adjacent terms without an operator are treated as `AND`. Quoted phrases must use double quotes.

## Viewing Product Details

Product detail pages show descriptions, costs, images, and attribution details. Use the product name links from department pages, search results, or the cart to open the detail page.

## Using the Cart

The cart is a planning aid stored locally in your browser. It does not submit orders or synchronize across devices.
