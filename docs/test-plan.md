# Central Supply Catalog Test Plan

## Purpose

This plan defines the repeatable checks used to validate the Central Supply Catalog build, browser workflows, accessibility regression coverage, and performance budgets.

## Test Environment

- Node.js 24.
- npm dependencies installed with `npm ci`.
- Playwright bundled Chromium installed with `npm run test:install`.
- Production build generated by `npm run prod`.
- Production preview served on `http://127.0.0.1:4324/`.

## Test Commands

```bash
npm ci
npm run test:install
npm audit --audit-level=moderate
npm ls --depth=0
npm run validate:data
npm run build:search-index
npm run prod
npm test
npm run test:audit
```

## Manual Accessibility Checks

Manual checks are required before claiming WCAG conformance:

- Keyboard-only operation for side navigation, department menu, search, product purchase, and cart edits.
- Visible focus order and focus retention after menu, cart, and search state changes.
- Browser zoom at 200%.
- Text spacing overrides.
- Color contrast checks for normal, hover, focus, disabled, and status states.
- Screen reader pass for header navigation, search results, product detail, and cart totals.

## CI Coverage

`.github/workflows/validation.yml` runs:

- `npm ci`
- `npm run test:install -- --with-deps`
- `npm audit --audit-level=moderate`
- `npm ls --depth=0`
- `npm run validate:data`
- `npm run build:search-index`
- `npm run prod`
- `npm test`
- `npm run test:editor` through `npm test`
- `npm run test:audit`

## Reporting

- Playwright HTML reports are written to `reports/playwright-html/`.
- Lighthouse JSON reports are written to `reports/lighthouse/`.
